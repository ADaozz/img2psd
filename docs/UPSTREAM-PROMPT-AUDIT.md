## 本项目额外加固

上游的轮廓审查依然允许第二轮返修后不再复审并以 repaired 结束，这不是本次要恢复的要求。本项目改为：

- SVG 通过需要整图 svg/blend/edge、覆盖当前候选的全部选框的 2 倍 blend/edge，以及六项检查和逐区图像依据。证据绑定当前候选、参考和预览像素；旧版本或被替换预览不能复用。
- 补全后的完整 SVG 单独派发 completion-review，通过前不计为完成，不进入子层拆分或最终叠放。轮廓阶段的 pass 不能代替对新增形状的审查。
- SVG 轮廓及补全审批遇到 blocked 或轮数耗尽仍未通过会阻塞；Krita 审批行为本轮不改。
- 补全发布前复查 SVG 结构与父范围，保持只读底稿，仅允许重做完整新增路径数组。

机器只能约束几何格式与证据完整性，不能确认 agent 实际打开过图片，也不能自动判定语义归属与绘制质量。KRA 仍需执行者在 Krita 实际打开检查。

## 保留的本地规则与未等价项

- 素体无穿戴配饰，全部配饰归衣物绘制。上游将饰物混入头、颈、身体的规则不直接照搬；手套、鞋袜及其装饰也按本地衣物提取提示处理。
- 不恢复 Qwen 或单背景去背；GPT 原生 Alpha、Nano 工具内部双背景恢复按现有接口执行。
- 当前遮挡提案保持本地单 level 能力，不扩展多深度 schema。
- 最新上游允许轮廓阶段完全遮挡的部件先交空 SVG，隐藏形状留到补全。本项目当前仍要求非空轮廓；本次没有只改提示词就放开空稿校验。该生命周期差异尚未等价迁移。
- 姿态判断/标准姿态提示词不自动接入参考准备，当前仍按用户原姿态工作。
- 不移植嵌套 Codex 调度、宿主专用工具、模型档位配置；当前组 note 修正仍通过 notes.md 报告，不调用上游 update_group_note。
- 既有 job 的 instructions、raster.json 与已发布产物不会因为修改提示词就被自动重写。续跑需重新 next，并核对本次选择的提示词路径；已有栅格配置需自行补齐 step01 review。

## 本轮范围

按用户要求，当前只落地补全后的审批、相应的共同 SVG 审查约束及人物提示词/参考加载；衣物 profile、栅格模板和其他流程差异留待测试后处理。没有把全部上游行为声明为已等价迁移。
