# 头发拆分参考图

本目录保存三套人物模型贴图提取的参考板，供 `../children.md` 按当前发型和疑问选择。三张恢复的参考板已纳入版本管理，新签出即可使用；其余本地派生裁片继续忽略，配置本身不会下载或生成图片。

下列三张参考板与恢复来源 `tutorial/live2d-guidance/hair-reference-templates/` 中的同名文件字节一致，已放在本目录，供现有清单直接读取：

| 文件 | 参考价值 |
| --- | --- |
| `01-发区组织与前侧发拆分-Milly.png` | 区分完整刘海、前侧发、侧发与后发底形，观察隐藏发根；发区名称由同一角色 PSD 辅助核对。 |
| `02-长发主束与细束的粒度对照-莉尔.png` | 比较完整长发片与细发片，避免只取小碎发代替完整侧发。 |
| `03-长卷发整束与多尖发面-樱桃蛋糕天使.png` | 长卷曲、多尖末端与丰富发纹仍可属于一件完整 part，避免按弯折或发尖机械细分。 |

主 hair 清单读取本目录；back_hair 清单显式复用这三张板，bangs 清单只配置 Milly。路径相对各自的 `children.references.json` 解析。缺少已配置图片会停止该次分析并报错；如果使用自己的图片，需要同时调整清单的路径、用途及提示词中的说明。

模型通过 附加参考清单 收到图片路径和用途，再按需调用 图片查看能力。PNG 图集只提供发片形体先验，不能据其排布推断原 PSD 分组、独立运动或遮挡顺序；当前角色、父完成 SVG 和控制需求优先。
