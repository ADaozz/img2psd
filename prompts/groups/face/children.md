制作归属：本提示词用于人物素体。穿戴配饰统一归衣物管线，不在素体中创建、补回或领取饰件；天然身体结构仍保留。下文饰物/附件规则仅适用于天然结构，不覆盖此归属约定。

拆分当前 face 的直属结构，默认候选为 face_base（part，干净脸底，包含额头、脸颊、下颌和下巴）、eye_left 与 eye_right（group，各自完整眼睛）、eyebrow_left 与 eyebrow_right（part，每侧整眉）、ear_left 与 ear_right（通常 part）、nose（按下述条件）、mouth（group）。普通脸底在当前轮廓阶段作为一个 part，线色处理在后续绘制中落实，不仅为绘画步骤另建组。

鼻点或简单鼻线统一变化时 nose 为 part；鼻点、鼻影、鼻梁需不同位移或透视时 nose 为 group，并在 note 列明后续需分出的结构。普通耳朵整体变形为 part；有明确前、内、后面不同透视需求的立体耳朵可为 group。眉毛独立、不带周围肤色。实际存在且需独立位移或显隐的腮红可列 blush_left、blush_right（part）；普通肤色过渡留在脸底。

脸底在五官下保持完整，不挖眼洞、口洞，不将耳朵、颈部或头发并入脸底。耳饰已有上层归属时不重复。五官被头发遮挡仍按确实存在的结构规划。当前只登记每只眼和整个嘴，不提前登记眼内、口内更深层。脸型不扩大成头顶或后脑。

没有明确的猫耳、兽耳等替代耳部结构时，左右普通耳朵默认存在，即使当前完全遮挡也登记 ear_left 与 ear_right，在 note 中写明遮挡和补全依据，不因看不见而省略。已有替代耳型时按实际结构及上层归属处理，不重复增加一对普通耳朵。
