对照参考图和本层各组的轮廓 SVG，统一处理被多个组重复制作的同一个可见对象。先查看整层合成预览与原图的叠加，再按需要分别查看各组和裁剪放大的疑似重复区域。

增量续跑时，sourceSvg 是该件当前有效底稿：reusedReduction 为 true 表示已有输入一致的去重结果，originalOutline 保留最初轮廓供核对。未重画且不需要实际修改的部件保持 sourceSvg 原样；不因同层有其他部件重画就重做所有部件。只有发现真实重复并需要改变该件输出时才提交它的 changed。

先核对实体身份和分层职责，再判断重复。只有两处确实是同一个实体的重复领取，且没有各自独立的遮挡层级、连接根部、运动或变形职责，才进入去重。当前正面轮廓重合、像素接触、颜色相似或看起来能够接成一束，都不足以证明是副本。本步不重新设计已经分析出的分层和控制结构。

分组名称作为制作范围使用，不要求纠正所有类别：发束完整落在头饰组也可以保留。同一个对象被重复画在两个组时，选择一个已有归属保留，只清理另一个组的重复部分。合理遮挡补形、身体接缝的重叠不构成重复对象，不能按像素重叠直接全部相减。保留可靠的可见边缘、孔洞和独立区域，去重前后主体的可见覆盖应保持完整，不添加无关结构。

子层可能混合 group 与 part。脸底与五官、眼白与虹膜、口内与牙舌、躯干底形与 breast、后发底形与前发是不同控制单元的合法覆盖，不能因色块相交或位于同一个父范围就相减。去重只针对同一真实对象被重复领取；先核对每个节点的 note 与父组，保留底形在上层部件后方的完整承接。不会因子组名字与祖先相似就删除它，也不把父组引导图作为本层候选参与去重。

头发尤其要区分前发、独立鬓发和后发的前后层。side_hair 的 note 若明确它是刘海下伸出、长后发前方的独立鬓束，就保留这件完整实体及隐藏发根；不能因为 bangs 或 back_hair 的投影覆盖、曲线相连，就把鬓发删空。不同发区在当前姿态拥有重合轮廓也可以是合法分层。如果某组额外误画了属于另一发区的实体，应清理误领取的副本，不能以连续性为由反过来取消明确的独立分层。

确认属于同一实体、同一控制职责的重复后，归属才以连续性优先：同一个对象能够与某组主体自然相连、合并成连续形体时，优先在该组保留完整版本，不把本来可以合为整体的同一对象分散到多个组。若另一组中只存在独立、悬空或与主体没有自然连接的一段重复片段，优先去除该片段。依据参考图中的结构走向和实际连接关系判断连续性，不能仅凭像素接触或组名判断。真正独立且未在其他组重复出现的区域仍须保留，不因独立就删除。

整组清空前，必须逐项确认其原有职责已由同一实体、同一控制层的完整副本承担，并在处理说明中写清依据；“被其它色块盖住”或“另一组更连续”不是依据。分层说明与图像理解冲突、无法确认同一实体或独立运动关系时，保留各组并在 note 中记录疑点，后续检查归属，不自行合并或删除层级。

仅修改实际需要去重的组，写入本轮指定草稿。源 SVG、正式输出、groups.json 和历史记录由程序管理。保持同一画布、viewBox、当前组 data-group-path 和可编辑矢量。子组仍须位于其父组完成 SVG 内。若组被完整去除，仍写一个含组容器的空 SVG，明确表达空结果。

修改后通过原图叠加、边缘图及局部放大自检，确认重复对象只保留一次，没有误删其他形体或破坏可靠边缘。提交实际修改的组和处理说明；未修改的组由程序原样保留。不启动独立 review 或生图。
